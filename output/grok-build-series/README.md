# Inside Grok Build — Editorial Package

The publication edition is written as one continuous first-principles story. A platform engineer named Mira begins with a failed agent task and discovers each harness boundary only when the incident makes that mechanism necessary. Chapters target a focused 10–15 minute read; source evidence follows the intuition instead of leading it.

This directory contains the requested work in publication order:

1. [`00-existing-series-style-analysis.md`](00-existing-series-style-analysis.md)
2. Research scope/version and dossier: [`01-research-dossier.md`](01-research-dossier.md)
3. Series architecture, SEO/publication plan, and all detailed outlines: [`02-series-architecture-seo-and-outlines.md`](02-series-architecture-seo-and-outlines.md)
4. Full Article 1 draft: [`03-article-01-grok-build-is-more-than-a-coding-cli.md`](03-article-01-grok-build-is-more-than-a-coding-cli.md)
5. Article 1 source/verification ledger: [`04-article-01-source-and-verification-ledger.md`](04-article-01-source-and-verification-ledger.md)

After editorial approval, the package was expanded with full generated Markdown drafts for Articles 1–14. The canonical publication pages live under `site/posts/grok-build-*.html`; the generation source is `scripts/build-grok-series.mjs` plus `scripts/grok-series-articles-07-14.mjs`.

Every published article clears the site's 4,000-word long-form gate and contains source-backed contract walks, an inline SVG, a worked example, audit tables, failure drills, FAQ, takeaways, and references.
