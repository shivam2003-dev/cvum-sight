DMML references -- books, patterns, tools and terms.

dmml references data-engineering mlops

The course-aligned reading shelf for Data Management for Machine Learning: data engineering lifecycle, data-intensive systems, dimensional modeling, pipeline practice, ML reliability and data infrastructure. Use this as a focused reference list, not as a shopping list.

Primary books from the decks

  • Reis & Housley -- Fundamentals of Data Engineering -- best overall match for the course lifecycle: generation, storage, ingestion, transformation, serving, security, DataOps and architecture.
  • Martin Kleppmann -- Designing Data-Intensive Applications -- data models, encoding/serialization, schema evolution, replication, consistency, services, logs and streams.
  • Chen, Murphy, Parisa, Sculley & Underwood -- Reliable Machine Learning -- ML pipeline reliability, monitoring, incident response, data/model drift and production discipline.
  • James Densmore -- Data Pipelines Pocket Reference -- practical pipeline design, ELT/ETL, orchestration and operational concerns.
  • Ville Tuulos -- Effective Data Science Infrastructure -- data science/ML platform layers, compute, scheduling, versioning and model development.
  • Kimball & Ross -- The Data Warehouse Toolkit -- dimensional modeling, facts, dimensions, star schemas, snowflake schemas and marts.

Terms to keep straight

TermOne-line meaning
Data productOwned, discoverable, reliable data asset with defined consumers and quality contract.
MetadataData about data: schema, owner, freshness, lineage, quality, access policy.
LineageWhere data came from and which transformations produced it.
CDCChange data capture: stream inserts/updates/deletes from a source database.
Reverse ETLMove warehouse/model outputs back into operational tools like CRM.
DataOpsDevOps discipline applied to data pipelines: tests, versioning, monitoring and automation.
CT/CDContinuous training and continuous deployment for ML systems.
Data swampData lake without metadata, quality, governance or trust.

Useful free reads

  • Data Engineering Wiki -- broad community map of data engineering terms and tools.
  • Martin Fowler -- How to Move Beyond a Monolithic Data Lake to a Distributed Data Mesh -- domain ownership and data-as-a-product thinking.
  • Martin Fowler -- Evolutionary Database Design -- schema change discipline and compatibility.
  • Confluent -- Stream Processing series -- practical introduction to event streams and stream processing architecture.
  • dbt docs -- Analytics engineering introduction -- SQL transformation, tests, lineage and documentation.
  • Apache Airflow docs -- orchestration concepts and DAG scheduling.
  • Delta Lake, Apache Iceberg, Apache Hudi -- lakehouse table formats.
