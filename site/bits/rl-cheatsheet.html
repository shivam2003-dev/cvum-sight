RL cheatsheet — the whole mid-sem on one card.

rl cheatsheet bellman revision

Dense, scannable revision card for CS1–CS7: vocabulary, every key equation, ε-greedy, the Bellman equations, policy & value iteration, and Monte Carlo — with one-line meanings. Cram from this; understand it from the slides explained.

Vocabulary

TermMeaning
AgentThe learner/decision-maker.
EnvironmentEverything outside the agent.
State SₜThe current situation.
Action AₜWhat the agent does.
Reward RₜScalar feedback after an action.
Return GₜCumulative (discounted) future reward.
Policy π(a\|s)Rule mapping states → action probabilities.
Value v_π(s)Expected return from s under π.
ModelAgent's idea of the dynamics (optional).
γDiscount rate, 0≤γ≤1.
αStep size / learning rate.
εExploration probability.

Bandits (CS2–3)

True value:     q*(a) = E[Rₜ | Aₜ=a]
Estimate:       Q_t(a) = (sum of rewards for a) / (times a taken)
Incremental:    Q ← Q + α (R − Q)          # α=1/n ⇒ sample average
Greedy:         A_t = argmax_a Q_t(a)        # exploit
ε-greedy:       prob 1−ε exploit, prob ε random   # explore
Non-stationary: use constant α (recent rewards weigh more)
Optimistic init: high Q₀ ⇒ free early exploration
Ex-1: 2 actions, ε=0.5 ⇒ P(greedy)=1·0.5+0.5·0.5=0.75

MDP & returns (CS3–5)

Dynamics:   p(s′,r|s,a) = Pr{Sₜ=s′,Rₜ=r | S_{t−1}=s, A_{t−1}=a}
Markov:     future depends only on current state+action
Return:     G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + … = Σ γ^k R_{t+k+1}
Recursion:  G_t = R_{t+1} + γ G_{t+1}
Const +1:   Σ γ^k = 1/(1−γ)
State value:  v_π(s) = E_π[G_t | S_t=s]
Action value: q_π(s,a) = E_π[G_t | S_t=s, A_t=a]

Bellman equations

Expectation: v_π(s) = Σ_a π(a|s) Σ_{s′,r} p(s′,r|s,a)[ r + γ v_π(s′) ]
Optimality:  v*(s)  = max_a   Σ_{s′,r} p(s′,r|s,a)[ r + γ v*(s′) ]
Optimal policy: greedy w.r.t. v*  (or argmax_a q*(s,a))

Dynamic programming (CS4–6)

MethodUpdateGives
Policy evaluationBellman expectation backup, sweep to convergencev_π
Policy improvementπ′(s)=argmax_a Σ p[r+γv_π(s′)]≥ old policy
Policy iterationevaluate ⇄ improveoptimal π
Value iterationBellman optimality backup, once/sweepv* → optimal π

All are instances of Generalized Policy Iteration (GPI). Needs the model + full sweeps.

Monte Carlo (CS6–7)

Idea:  v_π(s) ≈ average of returns observed after visiting s  (model-free, episodic)
First-visit MC: avg return after first visit to s per episode
Every-visit MC: avg return after every visit
Control: estimate q_π(s,a), improve greedily (GPI loop)
Cover all (s,a): exploring starts | on-policy ε-soft | off-policy + importance sampling
One-line map. Bandits = explore/exploit, no states. MDP = the model of sequential decisions. Bellman = value today via value tomorrow. DP = solve a known model. MC = learn from sampled episodes when you don't know the model.
