Dense, scannable revision card for CS1–CS7: vocabulary, every key equation, \(\varepsilon\)-greedy, the Bellman equations, policy & value iteration, and Monte Carlo — with one-line meanings. Cram from this; understand it from the slides explained.

Vocabulary

TermMeaning

State \(S_t\)The current situation.

Policy \(\pi(a\mid s)\)Rule mapping states → action probabilities.

Bandits (CS2–3)

\[ q_*(a) = \mathbb{E}[R_t\mid A_t=a] \qquad Q_t(a) = \frac{\text{sum of rewards for }a}{\text{times }a\text{ taken}} \]
\[ Q \leftarrow Q + \alpha\,(R - Q) \quad(\alpha=\tfrac1n \Rightarrow \text{sample average}) \qquad A_t = \arg\max_a Q_t(a) \]
  • Greedy exploits; \(\varepsilon\)-greedy explores a random action with prob. \(\varepsilon\) so estimates converge.
  • Non-stationary → constant \(\alpha\) (recent rewards weigh more). Optimistic init → free early exploration.
  • Ex-1: two actions, \(\varepsilon=0.5\) \(\Rightarrow\) \(P(\text{greedy}) = 1\cdot 0.5 + 0.5\cdot 0.5 = 0.75\).

MDP & returns (CS3–5)

\[ p(s',r\mid s,a) = \Pr\{S_t=s',R_t=r \mid S_{t-1}=s, A_{t-1}=a\} \]
\[ G_t = \sum_{k=0}^{\infty}\gamma^k R_{t+k+1} = R_{t+1} + \gamma G_{t+1} \qquad \sum_{k=0}^\infty \gamma^k = \tfrac{1}{1-\gamma} \]
\[ v_\pi(s) = \mathbb{E}_\pi[G_t\mid S_t=s] \qquad q_\pi(s,a) = \mathbb{E}_\pi[G_t\mid S_t=s, A_t=a] \]

Markov property: the future depends only on the current state and action.

Bellman equations

\[ v_\pi(s) = \sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)\big[r + \gamma v_\pi(s')\big] \]
\[ v_*(s) = \max_a \sum_{s',r} p(s',r\mid s,a)\big[r + \gamma v_*(s')\big] \qquad \pi_*(s)=\arg\max_a q_*(s,a) \]

Dynamic programming (CS4–6)

MethodUpdateGives
Policy evaluationBellman expectation backup, sweep to convergence\(v_\pi\)
Policy improvement\(\pi'(s)=\arg\max_a \sum p[r+\gamma v_\pi(s')]\)\(\ge\) old policy
Policy iterationevaluate \(\rightleftarrows\) improveoptimal \(\pi\)
Value iterationBellman optimality backup, once/sweep\(v_* \to\) optimal \(\pi\)

All are instances of Generalized Policy Iteration (GPI). Needs the model + full sweeps.

Monte Carlo (CS6–7)

\[ v_\pi(s) \approx \text{average of returns observed after visiting } s \quad(\text{model-free, episodic}) \]
  • First-visit MC: avg return after the first visit to \(s\) per episode. Every-visit MC: after every visit.
  • Control: estimate \(q_\pi(s,a)\), improve greedily (GPI loop).
  • Cover all \((s,a)\): exploring starts | on-policy \(\varepsilon\)-soft | off-policy + importance sampling.
One-line map. Bandits = explore/exploit, no states. MDP = the model of sequential decisions. Bellman = value today via value tomorrow. DP = solve a known model. MC = learn from sampled episodes when you don't know the model.
