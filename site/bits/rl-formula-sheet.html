BITS · RL · formula sheet · CS1–CS7

RL formula sheet — every equation, every symbol defined.

rl formulas bellman reference

Every equation for the mid-sem, with each symbol spelled out — bandits, returns, model dynamics, value functions, the Bellman equations, DP backups, and the Monte Carlo estimate. Pair with the slides explained.

Symbols

SymbolMeaning
Sₜ, Aₜ, Rₜstate, action, reward at step t
π(a\|s)policy: prob. of action a in state s
Gₜreturn (cumulative future reward)
γdiscount rate, 0 ≤ γ ≤ 1
αstep size / learning rate
εexploration probability
q*(a)true value of bandit action a
Q_t(a)estimated value of a at step t
v_π(s), q_π(s,a)state-/action-value under policy π
v*(s), q*(s,a)optimal state-/action-value
p(s′,r\|s,a)model dynamics

Bandits

q*(a)  = E[ Rₜ | Aₜ = a ]                       # true action value
Q_t(a) = (Σ rewards for a before t) / (count a before t)
Q_{n+1} = Q_n + (1/n)(R_n − Q_n)               # sample-average, incremental
Q_{n+1} = Q_n + α (R_n − Q_n),  0<α≤1           # constant α (non-stationary)
A_t = argmax_a Q_t(a)                          # greedy
P(non-greedy) = ε ;  P(greedy) = 1 − ε + ε/|A| # ε-greedy

Returns

G_t = R_{t+1} + R_{t+2} + … + R_T              # episodic
G_t = Σ_{k=0}^∞ γ^k R_{t+k+1}                  # discounted / continuing
G_t = R_{t+1} + γ G_{t+1}                       # recursion
Σ_{k=0}^∞ γ^k = 1/(1−γ)                         # constant reward +1, γ<1

Model dynamics

p(s′,r | s,a) = Pr{ Sₜ=s′, Rₜ=r | S_{t−1}=s, A_{t−1}=a }
p(s′ | s,a)   = Σ_r p(s′,r | s,a)              # state-transition prob.
r(s,a)        = Σ_r r Σ_{s′} p(s′,r | s,a)     # expected reward
r(s,a,s′)     = Σ_r r · p(s′,r|s,a) / p(s′|s,a)

Value functions

v_π(s)   = E_π[ G_t | S_t = s ]
q_π(s,a) = E_π[ G_t | S_t = s, A_t = a ]
v_π(s)   = Σ_a π(a|s) q_π(s,a)

Bellman equations

# expectation (for a given policy π)
v_π(s) = Σ_a π(a|s) Σ_{s′,r} p(s′,r|s,a) [ r + γ v_π(s′) ]
q_π(s,a) = Σ_{s′,r} p(s′,r|s,a) [ r + γ Σ_{a′} π(a′|s′) q_π(s′,a′) ]

# optimality (best over all policies)
v*(s)   = max_a Σ_{s′,r} p(s′,r|s,a) [ r + γ v*(s′) ]
q*(s,a) = Σ_{s′,r} p(s′,r|s,a) [ r + γ max_{a′} q*(s′,a′) ]
π*(s)   = argmax_a q*(s,a)                      # optimal policy

Dynamic programming backups

# policy evaluation (iterate to convergence)
v(s) ← Σ_a π(a|s) Σ_{s′,r} p(s′,r|s,a)[ r + γ v(s′) ]
# policy improvement
π′(s) = argmax_a Σ_{s′,r} p(s′,r|s,a)[ r + γ v_π(s′) ]
# value iteration
v(s) ← max_a Σ_{s′,r} p(s′,r|s,a)[ r + γ v(s′) ]

Monte Carlo

v_π(s) ≈ (1/N) Σ_i G_i^(s)        # average returns observed from s
Q(s,a) ← Q(s,a) + (1/N)(G − Q(s,a))   # incremental MC for action values
# off-policy importance-sampling ratio
ρ_{t:T−1} = Π_{k=t}^{T−1} π(A_k|S_k) / b(A_k|S_k)
Read it as one chain. Define the return → take its expectation to get value → expand the recursion to get Bellman → turn Bellman into a backup to get DP → replace the expectation with a sample average to get Monte Carlo.
