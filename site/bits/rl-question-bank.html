RL question bank — questions only, no answers.

rl questions exam-prep active-recall

Exam-style questions pulled straight from the CS1–CS7 slides — grouped by lecture, questions only, no answers. Work them cold, then check yourself against the slides explained and formula sheet.

How to use. Close the other tabs. Attempt each from memory in writing (mid-sem is hand-written, scanned). Only then check. The struggle to recall is the learning.

CS1 — intro & elements

  1. Define reinforcement learning. Why is it called feedback-based learning?
  2. Is RL a type of neural network? Justify in one or two lines.
  3. Compare supervised, unsupervised, and reinforcement learning across: data, type of problem, objective, and a sample algorithm each.
  4. State three situations in which RL is the right tool.
  5. Draw the agent–environment interaction loop. Label state, action, and reward, and write the resulting sequence of symbols.
  6. Name and define the four sub-elements of an RL system beyond the agent and environment.
  7. Distinguish a reward signal from a value function. Can a low-reward state have high value? Explain.
  8. List the four characteristics of RL. Why is delayed feedback a difficulty?
  9. Using a child learning to ride a bicycle, identify the agent, an action, a state, and a reward.

CS2–CS3 — multi-armed bandits

  1. State the k-armed bandit problem and its objective.
  2. Define the value of an action, \(q_*(a)\). If you knew every \(q_*(a)\), how would you act?
  3. Write the sample-average estimate \(Q_t(a)\). Given pulls of arm \(a\) returning \(-1, -1, 5\), compute \(Q(a)\).
  4. Write the incremental update rule for Q. What step size reproduces the sample average exactly?
  5. Define greedy and \(\varepsilon\)-greedy action selection. State the exploration–exploitation dilemma.
  6. Why does \(\varepsilon\)-greedy guarantee \(Q_t(a)\) converges to \(q_*(a)\) in the limit?
  7. Ex-1: In \(\varepsilon\)-greedy with two actions and \(\varepsilon = 0.5\), what is the probability the greedy action is selected? Show your working.
  8. For a non-stationary bandit, why is a constant step size \(\alpha\) preferred over \(\tfrac1n\)? What kind of average does it produce?
  9. Explain how optimistic initial values encourage exploration without using \(\varepsilon\).
  10. Describe the 10-armed testbed: how are the true values and the rewards generated, and how is a method's average behaviour measured?

CS3–CS5 — MDPs, returns, value functions

  1. List the components that define an MDP.
  2. Write the model-dynamics function \(p(s',r\mid s,a)\) and state the Markov property in words.
  3. From \(p(s',r\mid s,a)\), how do you obtain the state-transition probability \(p(s'\mid s,a)\)?
  4. For the noisy grid world, give the movement probabilities for action "North" and the per-step and terminal rewards.
  5. For the recycling robot: list its states, the actions available in each, and explain why \(r_{\text{search}} > r_{\text{wait}}\) and why a \(-3\) reward appears.
  6. State the reward hypothesis. Give one example where rewarding sub-steps instead of the goal backfires.
  7. Define the return G_t for an episodic task and for a continuing task. Why is discounting needed for continuing tasks?
  8. Write the discounted return and derive the recursion \(G_t = R_{t+1} + \gamma G_{t+1}\).
  9. For a constant reward of \(+1\) every step with \(\gamma < 1\), evaluate the return.
  10. Define a policy \(\pi(a\mid s)\), the state-value \(v_\pi(s)\), and the action-value \(q_\pi(s,a)\).
  11. Write the Bellman expectation equation for \(v_\pi(s)\) and explain each part in words.
  12. Write the Bellman optimality equation for \(v_*(s)\). What single change distinguishes it from the expectation equation? How do you read off the optimal policy?

CS4–CS6 — dynamic programming

  1. What problem does iterative policy evaluation solve, and what backup does it repeat?
  2. State the policy improvement step and what the policy improvement theorem guarantees.
  3. Describe policy iteration. Why does it terminate in finite time for a finite MDP?
  4. Write the value-iteration update. How does it differ from policy evaluation, and how do you extract the optimal policy afterwards?
  5. What is Generalized Policy Iteration (GPI)?
  6. State two limitations of dynamic programming that motivate model-free methods.

CS6–CS7 — Monte Carlo methods

  1. What is the core idea of Monte Carlo value estimation? What kind of task does it require?
  2. Distinguish first-visit from every-visit Monte Carlo prediction.
  3. Why do MC control methods estimate action values \(q_\pi(s,a)\) rather than state values?
  4. What problem does "exploring starts" solve, and how?
  5. Contrast on-policy and off-policy MC control. What is importance sampling used for?
  6. Compare DP and MC on: need for a model, and when updates happen. Name one trade-off MC introduces.
