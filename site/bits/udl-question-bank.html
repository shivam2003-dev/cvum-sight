Autoencoders and convolution calculations

Q1 -- transposed convolution feature map EC-2 regular

A \(2\times2\) image \(I=\begin{bmatrix}25&60\\10&30\end{bmatrix}\) and kernel \(F=\begin{bmatrix}1&0&-1\\1&0&-1\\1&0&-1\end{bmatrix}\) are used in transposed convolution with valid padding and stride 2. Find the output size and feature-map values.

Show worked answer

For transposed convolution, each input value places a scaled copy of the \(3\times3\) kernel into the output grid, shifted by stride 2. With input size 2, kernel size 3 and stride 2, output size is:

\[ (2-1)\cdot2 + 3 = 5 \]

So the feature map is \(5\times5\).

\[ \begin{bmatrix} 25&0&35&0&-60\\ 25&0&35&0&-60\\ 35&0&55&0&-90\\ 10&0&20&0&-30\\ 10&0&20&0&-30 \end{bmatrix} \]

Q2 -- binary autoencoder activation, loss and update EC-2 regular

A fully connected autoencoder has 2D binary input, one hidden layer with sigmoid activation, zero bias and input \((x_1=1,x_2=0)\). Choose output activation, loss, compute loss at iteration \(t\), and update weights \(w_1,w_3\) by ordinary gradient descent. Source solution reports output \((0.62,0.5)\), learning rate 0.25, and relevant hidden activation 0.5.

Show worked answer

For binary reconstruction, choose sigmoid output activation so each output is a Bernoulli probability. Use sum of binary cross-entropy across output nodes.

For target \((1,0)\) and source-reported output \((0.62,0.5)\), the source solution uses the positive terms:

\[ L=-\ln(0.62)-\ln(0.5)=1.165 \]

Gradient update pattern:

\[ w_3^{t+1}=w_3^t-\eta(\hat{x}_1-x_1)h \] \[ w_1^{t+1}=w_1^t-\eta(\hat{x}_1-x_1)w_3 h(1-h)x_1 \]

With \(\eta=0.25\), \(\hat{x}_1=0.62\), \(x_1=1\), \(h=0.5\), source form:

\[ w_3^{t+1}=1-0.25(0.62-1)(0.5) \] \[ w_1^{t+1}=0-0.25(0.62-1)(1)(0.5)(1-0.5)(1) \]

Q3 -- 1D linear autoencoder with L2 regularization EC-2 regular

A single hidden layer autoencoder has scalar input \(X\), hidden \(Z=\alpha X\), output \(Y=\beta Z\), identity activations and zero bias. \(X\sim U[-2,2]\). Minimize expected squared error plus \(0.5(\alpha^2+\beta^2)\). Find \(\alpha,\beta\).

Show worked answer

The reconstruction is \(\hat{X}=\alpha\beta X\). Since \(X\sim U[-2,2]\), \(E[X^2]=4/3\). Objective:

\[ J=\frac{4}{3}(1-\alpha\beta)^2+0.5(\alpha^2+\beta^2) \]

By symmetry, optimum has \(\alpha=\beta=s\) up to sign. Then:

\[ J(s)=\frac{4}{3}(1-s^2)^2+s^2 \]

Let \(u=s^2\). Differentiate:

\[ \frac{dJ}{du}=\frac{4}{3}(-2+2u)+1=\frac{8u-5}{3}=0 \]

So \(u=5/8\), and:

\[ \alpha=\beta=\pm\sqrt{\frac{5}{8}}=\pm 0.7905 \]

Q4 -- convolutional autoencoder encoder dimensions Lecture 8 tip

Encoder: Conv2D(32,(3,3),padding='same',input_shape=(28,28,1)), MaxPooling2D((2,2)), Conv2D(64,(3,3),padding='same'), MaxPooling2D((2,2)), Flatten(), Dense(30,name='latent'). Determine output dimensions, first conv parameters, why latent has 30 neurons, and effect of removing pooling.

Show worked answer
LayerOutput shapeReason
Input\(28\times28\times1\)MNIST-style grayscale image.
Conv2D 32, same\(28\times28\times32\)Same padding preserves height/width; 32 filters.
MaxPool 2x2\(14\times14\times32\)Halves spatial dimensions.
Conv2D 64, same\(14\times14\times64\)Same padding; 64 filters.
MaxPool 2x2\(7\times7\times64\)Halves again.

First conv trainable parameters:

\[ (3\cdot3\cdot1+1)\cdot32=320 \]

The 30-neuron latent layer is the bottleneck. It forces the encoder to keep compact features needed for reconstruction. Removing pooling keeps larger feature maps, increases flatten size and compute, weakens compression pressure, may preserve more detail, but can make the latent representation less meaningful and training heavier.

Q5 -- changing 3x3 conv kernels to 7x7 Lecture 8 tip

Two Conv2D layers change from \(3\times3\) kernels to \(7\times7\): Conv2D(32) and Conv2D(64). How do parameters, training time, receptive field and reconstruction accuracy change?

Show worked answer

Parameter count grows with \(k_hk_wc_{in}c_{out}\). If first layer input has 1 channel:

\[ 3\times3: (9\cdot1+1)32=320,\qquad 7\times7: (49\cdot1+1)32=1600 \]

For the second layer with 32 input channels and 64 filters:

\[ 3\times3: (9\cdot32+1)64=18{,}496,\qquad 7\times7: (49\cdot32+1)64=100{,}416 \]

Training time increases because each convolution has many more multiply-adds. Receptive field increases because each output sees a larger local patch. Reconstruction may improve if larger context matters, but may over-smooth, overfit, cost more memory/time, and lose local detail if not regularized.

Probability, PCA and factor methods

Q6 -- Laplace MLE for \(\{-2,-1,0,2,3\}\) EC-2 regular

Data instances \(\{-2,-1,0,2,3\}\) are sampled from a Laplace distribution. Find MLE of \((\mu,\sigma)\), where \(\sigma\) is the Laplace scale.

Show worked answer

For Laplace \(p(x|\mu,\sigma)=\frac{1}{2\sigma}\exp(-|x-\mu|/\sigma)\), the MLE for \(\mu\) is the sample median. Sorted data: \(-2,-1,0,2,3\). Median:

\[ \hat{\mu}=0 \]

Scale MLE is mean absolute deviation from the median:

\[ \hat{\sigma}=\frac{|{-2}|+|{-1}|+|0|+|2|+|3|}{5}=\frac{8}{5}=1.6 \]

Answer: \((\hat{\mu},\hat{\sigma})=(0,1.6)\).

Q7 -- Laplace MLE for \(\{2,1,0,-1,-3\}\) EC-2 regular

Data instances \(\{2,1,0,-1,-3\}\) are sampled from a Laplace distribution. Find MLE of \((\mu,\sigma)\).

Show worked answer

Sorted data: \(-3,-1,0,1,2\). Median:

\[ \hat{\mu}=0 \]

Scale:

\[ \hat{\sigma}=\frac{2+1+0+1+3}{5}=\frac{7}{5}=1.4 \]

Answer: \((0,1.4)\).

Q8 -- PCA complexity, ICA application, continuous point probability EC-2 makeup

Give computational complexity of standard PCA, randomized PCA and kernel PCA for \(N\) training instances of dimension \(d\). Name one ICA application. If \(x\) has a Gaussian density, what is \(P(x=0)\)?

Autoregressive models, MADE and PixelCNN

Q9 -- sampling from trained MADE EC-2 makeup

A trained MADE calculates \(p(x_1)\), \(p(x_2|x_1)\), \(p(x_3|x_2,x_1)\). \(x_1\) arrives first, then \(x_2\), then \(x_3\). Variables are binary. Show steps to generate \((x'_1,x'_2,x'_3)\).

Show worked answer

Use the autoregressive factorization:

\[ p(x)=p(x_1)p(x_2|x_1)p(x_3|x_1,x_2) \]
  1. Feed placeholder input such as \([0,0,0]\). Output node 1 does not depend on inputs. Sample \(x'_1\sim \operatorname{Bernoulli}(p(x_1=1))\).
  2. Feed \([x'_1,0,0]\). Output node 2 depends only on \(x'_1\). Sample \(x'_2\sim \operatorname{Bernoulli}(p(x_2=1|x'_1))\).
  3. Feed \([x'_1,x'_2,0]\). Output node 3 depends on \(x'_1,x'_2\). Sample \(x'_3\sim \operatorname{Bernoulli}(p(x_3=1|x'_1,x'_2))\).

Final generated instance: \([x'_1,x'_2,x'_3]\).

Q10 -- designing MADE masks EC-2 regular/makeup

Design masks for MADE so output \(x_i\) depends only on previous variables \(x_{<i}\). Type B mask is used in output layer and Type A masks in previous layers. The source figure contains node numbering as an embedded image.

Show method answer

The extracted text does not include the embedded node-number figure, so exact binary mask matrices cannot be recovered safely from text. The exam method is:

  1. Assign each input variable degree \(m(x_i)=i\).
  2. Assign each hidden node an integer degree \(m(h)\in\{1,\ldots,D-1\}\) based on the node numbering/order in the figure.
  3. For hidden layers with Type A style restriction, allow connection \(u\to v\) only when \(m(u)<m(v)\) or as specified by the course's Type A convention.
  4. For output layer Type B, output \(x_i\) may connect from hidden units with \(m(h)\le i\) if predicting \(x_i\) uses previous allowed variables; use the course convention to prevent self-dependency in density output.
  5. Draw final connections wherever mask entry is 1 and remove connections where mask entry is 0.

For the separate subquestion "training parameters associated with output node 1", the source solution gives 3 parameters = 2 incoming weights from hidden-layer-2 node-1 units + 1 bias.

Q11 -- pros and cons of more MADE masks EC-2 makeup

What are the pros and cons of using more masks in MADE?

Show answer

Pros: better generalization across variable orderings, less overfitting to one order, order-agnostic learning, improved likelihood through ensembling over masks, more robust conditional modeling.

Cons: higher training time, more implementation complexity, noisier gradients when masks change often, possible memory overhead, and higher inference cost if multiple masks are ensembled.

Q12 -- Gated PixelCNN, PixelCNN++, PixelSNAIL EC-2 papers

Explain Gated PixelCNN architectural elements and utility. What advantages does PixelCNN++ offer over standard/Gated PixelCNN? Why is Gated PixelCNN preferred over PixelCNN? What advantages does PixelSNAIL offer over PixelCNN++?

Show answer

Gated PixelCNN elements: masked convolutions enforce raster-scan causality; vertical and horizontal stacks remove the blind spot; gated activation \(\tanh(\cdot)\odot\sigma(\cdot)\) improves expressivity; residual/skip connections stabilize deep training; optional conditioning injects class labels or side information.

Why Gated PixelCNN over PixelCNN: better receptive field because vertical/horizontal stacks avoid blind spots; gated residual blocks make the architecture more expressive and easier to train.

PixelCNN++ advantages: discretized mixture of logistics instead of 256-way softmax, downsampling for longer dependencies, improved architecture/regularization, better likelihood and sample quality.

PixelSNAIL over PixelCNN++: adds causal self-attention to masked convolutions, models long-range dependencies better, combines local convolutional context with global attention context, and often improves bits-per-dimension/sample quality. Source answer identifies PixelSNAIL as the variant with best receptive field among listed PixelCNN variants.

Q13 -- Parallel WaveNet EC-2 makeup

How does Parallel WaveNet alleviate the drawback of WaveNet?

Show answer

Original WaveNet is autoregressive, so it generates audio one sample at a time. That gives high quality but slow inference.

Parallel WaveNet trains a strong autoregressive teacher, then trains a parallel student based on inverse autoregressive flow (IAF) using probability density distillation / KL matching. At test time the student generates the waveform in parallel from latent noise. This keeps teacher-like quality while making sampling far faster, reported in the source as about 1000x faster.

Normalizing flows and invertibility

Q14 -- transform \(z\sim U[0,1]\), \(x=z^2\) EC-2 regular/tip

Consider transforming a uniform base density \(z\in[0,1]\) using \(x=f(z)=z^2\). Find \(p_X(x)\).

Show worked answer

Since \(x=z^2\) and \(z\in[0,1]\), inverse is \(z=\sqrt{x}\), with \(x\in[0,1]\). Change of variables:

\[ p_X(x)=p_Z(\sqrt{x})\left|\frac{dz}{dx}\right| \]

Because \(p_Z(z)=1\) on \([0,1]\):

\[ p_X(x)=\frac{1}{2\sqrt{x}},\qquad 0<x\le1 \]

Outside \([0,1]\), density is 0.

Q15 -- invertibility checks EC-2 regular/tip

Are these invertible? Why? (i) \(z=f(x)=x^3-x^5+2x^7\), (ii) \(z=f(x)=\exp(-|x|)\), (iii) \(z=f(x)=x^2-x\).

Show worked answer

(i) \(f'(x)=3x^2-5x^4+14x^6=x^2(3-5x^2+14x^4)\). Let \(u=x^2\); \(14u^2-5u+3\) has negative discriminant \(25-168<0\) and positive leading coefficient, so it is always positive. Thus \(f'(x)\ge0\), with equality only at \(x=0\), and the function is strictly increasing overall. Invertible.

(ii) \(\exp(-|x|)\) is symmetric: \(f(1)=f(-1)\). Not one-to-one. Not invertible.

(iii) \(x^2-x\) is a parabola. For example \(f(0)=0\) and \(f(1)=0\). Not one-to-one. Not invertible.

Q16 -- RealNVP output and log determinant EC-2 makeup

In a RealNVP flow model, input \(x=[2,3]^T\). Find transformed \(y\) and log determinant of the Jacobian. Explain masking patterns and masking purpose. The source Word file stores the coupling equation/figure as an embedded image, so numeric \(s,t\) values are not in extracted text.

Show method answer

For a 2D affine coupling layer with \(x_1\) unchanged:

\[ y_1=x_1,\qquad y_2=x_2\exp(s(x_1))+t(x_1) \]

For \(x=[2,3]^T\):

\[ y_1=2,\qquad y_2=3\exp(s(2))+t(2) \]

Jacobian is triangular, so:

\[ \log|\det J|=s(2) \]

If the source figure gives actual \(s(2)\) and \(t(2)\), substitute those values in the two boxed formulas. Masking patterns: checkerboard masks for alternating image pixels, channel-wise masks for splitting channels. Masks keep part of the input fixed while transforming the other part, make inversion/log determinant easy, and are alternated so all variables are eventually transformed.

Q17 -- dequantization in flow models EC-2 makeup

How is dequantization done in flow models? Why is it needed?

Show answer

Dequantization adds continuous noise to discrete values, commonly:

\[ x_{\text{deq}}=x+u,\qquad u\sim U(0,1) \]

It is needed because normalizing flows model continuous densities, while image pixels are discrete integers. Directly fitting continuous densities to discrete points can create pathological likelihoods. Adding noise spreads each discrete point into a small continuous interval and makes density modeling well-defined. Flow++ improves this with variational dequantization.

Extra active-recall questions from lectures

Use these as short oral questions: define undercomplete AE; explain why linear AE equals PCA under linear/squared-error assumptions; distinguish histogram density estimation from parameterized maximum likelihood; explain why autoregressive sampling is slow; compare MAF and IAF; explain why flow Jacobians must be tractable; name RealNVP masks; compare PCA, ICA, CCA and LLE.

Show compact answer key
  • Undercomplete AE: code dimension smaller than input, forcing compression.
  • Linear AE equals PCA subspace when encoder/decoder are linear, squared loss is used, and inputs are normalized/centered.
  • Histogram counts bins directly; parameterized MLE searches \(\theta\) so \(p_\theta(x)\) fits data and generalizes.
  • Autoregressive sampling is slow because each variable needs previous sampled variables.
  • MAF: fast density, slow sampling. IAF: fast sampling, slower density.
  • Flow Jacobian determinant appears in change-of-variable likelihood, so it must be cheap.
  • RealNVP masks: checkerboard and channel-wise, alternated across layers.
  • PCA: variance directions; ICA: independent sources; CCA: correlated projections across two views; LLE: preserves local manifold reconstruction.
