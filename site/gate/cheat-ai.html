// how to use this

GATE DA AI on one page: search (uninformed, informed, adversarial), logic (propositional & predicate), and reasoning under uncertainty (conditional independence, Bayesian networks, exact inference by variable elimination, approximate inference by sampling). Know each search algorithm's completeness/optimality/complexity, and how to read a Bayes net.

// uninformed searchb=branch, d=depth
BFS: complete, optimal (unit cost), O(bᵈ) time & spacequeue; shallowest first.
DFS: not complete/optimal, O(bᵐ) time, O(bm) spacestack; memory-cheap.
UCS: complete, optimal; expands lowest path cost gDijkstra for trees.
IDDFS: complete, optimal (unit), DFS space, BFS optimalitybest of both.
// informed (heuristic) searchf = g + h
greedy best-first: f=h(n)fast, not optimal.
A*: f=g+hoptimal if h admissible (tree) / consistent (graph).
admissible: h ≤ true cost (never overestimates)→ A* optimal.
consistent: h(n) ≤ c(n,n′)+h(n′)stronger; → admissible.
// adversarial searchgames
minimax: MAX maximizes, MIN minimizesoptimal vs optimal opponent; O(bᵈ).
alpha-beta pruning: same result, prunes branchesbest-case O(b^(d/2)) with good ordering.
α = best for MAX so far, β = best for MINprune when α ≥ β.
// logicpropositional · predicate
¬ ∧ ∨ → ↔ ; A→B ≡ ¬A∨Bconnectives + implication identity.
valid (always T) · satisfiable (some T) · unsat (never)truth-table notions.
De Morgan: ¬(A∧B)=¬A∨¬Band vice versa.
modus ponens: A, A→B ⊢ Binference rule.
predicate: ∀ (for all), ∃ (exists); ¬∀x=∃x¬quantifier negation.
CNF, resolution for proofsrefutation: assume ¬goal, derive ⊥.
// reasoning under uncertaintyBayes nets
Bayes net: DAG, each node P(X | parents)compact joint distribution.
joint = Π P(Xᵢ | parents(Xᵢ))chain rule with independence.
node ⫫ non-descendants | its parentslocal Markov property.
d-separation → conditional independencechain/fork blocked by observed mid; collider opens when observed.
// inferenceexact vs approx
exact: variable eliminationsum out hidden vars one by one; order matters for cost.
marginalize: P(X)=Σ_others P(joint)sum out the rest.
approximate: samplingprior / rejection / likelihood weighting / Gibbs (MCMC).
rejection sampling: drop samples ≠ evidencewasteful if evidence rare.
likelihood weighting: fix evidence, weight by P(e|parents)no rejection.

exam traps

  • A* optimal ⇔ heuristic admissible (tree) / consistent (graph); overestimating breaks optimality.
  • DFS is not complete or optimal; BFS/UCS/IDDFS are. Know the completeness/optimality grid.
  • Alpha-beta gives the same value as minimax — only faster; pruning doesn't change the answer.
  • A→B ≡ ¬A∨B and De Morgan — used constantly in logic simplification.
  • Collider (v-structure): X→Z←Y are independent until you observe Z (or its descendant), then dependent — opposite of chains/forks.
  • Bayes net joint = product of P(node|parents) — the whole point of the structure.
  • Memorize the search algorithm grid: complete? optimal? time/space — pure recall MCQs.
  • A* admissibility/consistency and alpha-beta pruning are the favourite search questions.
  • Bayes nets: build the joint from P(node|parents), read independence via d-separation, infer by variable elimination (exact) or sampling (approx).
  • AI ties to Prob/Stats (Bayes) — reuse that machinery.
