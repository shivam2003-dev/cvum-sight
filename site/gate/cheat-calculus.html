Calculus & Optimization — Cheatsheet.

// how to use this

Single-variable calculus for GATE DA: limits, continuity, differentiability, derivative rules, Taylor series, and maxima/minima (single-variable optimization). Small syllabus, high accuracy expected — these are guaranteed marks if the rules are reflex.

// limits & continuityfoundations
limit exists ⇔ left = right limitboth sides agree.
continuous at a: lim_{x→a} f(x)=f(a)no jump/hole.
L'Hôpital: 0/0 or ∞/∞ → lim f′/g′differentiate top & bottom.
lim (sin x)/x =1 · lim (1+1/n)ⁿ=estandard limits.
// differentiability & rulesderivatives
differentiable ⇒ continuous (not converse)|x| continuous but not diff at 0.
product: (uv)′=u′v+uv′
quotient: (u/v)′=(u′v−uv′)/v²
chain: (f(g))′=f′(g)·g′most error-prone — go slow.
d/dx: xⁿ=nxⁿ⁻¹, eˣ=eˣ, ln x=1/xcore.
sin→cos, cos→−sin, tan→sec²trig.
// Taylor / Maclaurinseries
f(x)=Σ fⁿ(a)/n! ·(x−a)ⁿTaylor about a (a=0 → Maclaurin).
eˣ=1+x+x²/2!+x³/3!+…memorize.
sin x=x−x³/3!+x⁵/5!−…odd powers.
cos x=1−x²/2!+x⁴/4!−…even powers.
ln(1+x)=x−x²/2+x³/3−… · 1/(1−x)=Σxⁿ|x|<1.
// maxima & minima (1 variable)optimization
critical points: f′(x)=0 (or undefined)candidates for extrema.
f″>0 → local min · f″<0 → local maxsecond-derivative test.
f″=0 → inconclusive; check sign of f′first-derivative test / inflection.
global on [a,b]: compare f at crit pts + a,bdon't forget endpoints!
f′ changes + → − : max; − → + : minfirst-derivative test.

exam traps

  • Differentiable ⇒ continuous, but not the reverse — |x| is the counterexample. Classic one-marker.
  • Endpoints matter for global extrema on a closed interval — students check only f′=0 and miss the boundary.
  • f″=0 is inconclusive — fall back to the first-derivative (sign) test.
  • Chain rule on nested functions — the most common arithmetic slip; write each layer.
  • L'Hôpital only for 0/0 or ∞/∞ — rearrange other indeterminate forms first.
  • Optimization = critical points (f′=0) + second-derivative test + endpoints. Drill the routine.
  • Memorize the standard Taylor series (eˣ, sin, cos, ln, geometric) — they appear directly.
  • This is a small, high-accuracy subject — lost marks here are calculation slips, not concept gaps.
