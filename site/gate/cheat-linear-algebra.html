// how to use this

All of GATE DA Linear Algebra on one page: vector spaces, rank/nullity, solving systems, determinants, eigenvalues/eigenvectors, special matrices, and the decompositions (LU, SVD). LA is a top-weight, high-return area — these results are pure recall + plug-in. Memorize the boxes.

// vector spaces & independencefoundations
subspace: closed under + and scalar ·must contain 0.
linearly independent: Σcᵢvᵢ=0 ⇒ all cᵢ=0none is a combo of others.
basis = independent + spans#vectors = dimension.
n vectors in Rⁿ indep ⇔ det ≠ 0fast independence test.
// rank, nullity, systemsAx = b
rank = # pivots = # indep rows = # indep colsrow rank = col rank.
rank-nullity: rank(A)+nullity(A)=n (cols)nullity = dim of null space.
Ax=b: solution ⇔ rank(A)=rank([A|b])consistency test.
unique ⇔ rank = n (cols); else ∞ manyfree vars = n−rank.
Ax=0 has nonzero sol ⇔ rank < n ⇔ det A=0homogeneous.
Gaussian elimination → row echeloncount pivots = rank.
// determinant & inversedet facts
det(AB)=det A·det B · det(Aᵀ)=det Amultiplicative.
det(cA)=cⁿ det A · det(A⁻¹)=1/det An = size.
A invertible ⇔ det≠0 ⇔ rank=n ⇔ cols indepall equivalent.
det = Π eigenvalues · tr = Σ eigenvalueshuge shortcut.
triangular det = product of diagonalincl. after elimination.
// eigenvalues & eigenvectorsmost tested
Av=λv · solve det(A−λI)=0characteristic equation → λ.
Σλ = trace(A) · Πλ = det(A)check your λ's instantly.
eigvec: solve (A−λI)v=0null space of A−λI.
A symmetric → real λ, orthogonal eigvecsalways diagonalizable.
λ(Aᵏ)=λᵏ · λ(A⁻¹)=1/λ · λ(A+cI)=λ+ctransform shortcuts.
diagonalizable ⇔ n indep eigvecsA=PDP⁻¹.
// special matricesknow the defs
orthogonal: QᵀQ=I, Q⁻¹=Qᵀ, det=±1preserves length; λ on unit circle.
symmetric: A=Aᵀreal λ, orthogonal eigvecs.
idempotent: A²=Aλ∈{0,1}; projection matrix.
projection: P=A(AᵀA)⁻¹AᵀP²=P, Pᵀ=P.
positive definite: xᵀAx>0 ⇔ all λ>0symmetric; all pivots >0.
// quadratic forms & decompositionsLU · SVD
quadratic form: Q(x)=xᵀAxsign from λ's (def/semidef/indef).
LU: A=LU (lower×upper)from Gaussian elim; solve fast.
SVD: A=UΣVᵀ, any m×nU,V orthogonal; Σ singular values ≥0.
σᵢ = √(λᵢ of AᵀA)singular values; rank = # nonzero σ.

exam traps

  • Σλ=trace, Πλ=det — use to verify eigenvalues in seconds; forgetting this wastes time.
  • Symmetric ⇒ real eigenvalues + orthogonal eigenvectors — common one-marker.
  • det=0 ⇔ singular ⇔ rank<n ⇔ has nonzero null vector — all the same statement.
  • Ax=b consistency: compare rank(A) vs rank([A|b]); equal → solvable.
  • Idempotent λ∈{0,1}; orthogonal |λ|=1 — special-matrix eigenvalue facts.
  • nullity = n − rank (n = number of columns, not rows).
  • Eigenvalue questions = solve det(A−λI)=0, then verify with trace/det. Highest-frequency topic.
  • Every "is it solvable / unique" question is a rank question.
  • Memorize the special-matrix property table — pure recall marks.
  • SVD & PCA connect (PCA = eigen of covariance / SVD of data) — links to ML.
