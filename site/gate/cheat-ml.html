Machine Learning — Cheatsheet.

machine-learningregressionclassificationclusteringpca

// how to use this

All GATE DA ML on one page: supervised (regression + classification methods), the bias-variance trade-off, cross-validation, neural nets, and unsupervised (clustering, dimensionality reduction, PCA). ML is one of the heaviest-weight subjects in DA — know each method's idea, when it applies, and its key formula.

// regressionsupervised · continuous y
linear: ŷ = w·x + b, minimize MSEleast squares; closed form w=(XᵀX)⁻¹Xᵀy.
multiple linear: many featuressame, X is n×d.
ridge: MSE + λ‖w‖² (L2)shrinks weights; fights overfit/multicollinearity.
MSE = (1/n)Σ(yᵢ−ŷᵢ)² · R²=1−SSres/SStoterror metrics.
// classificationsupervised · discrete y
logistic: σ(w·x)=1/(1+e⁻ᵂˣ), cross-entropy losslinear decision boundary; outputs prob.
kNN: vote of k nearest; lazy, no trainingsmall k→overfit, large k→underfit.
naïve Bayes: P(y|x)∝P(y)ΠP(xᵢ|y)assumes feature independence.
LDA: assumes Gaussian, shared covariancelinear boundary; max class separation.
SVM: max-margin hyperplane; kernels for nonlinearsupport vectors define boundary.
decision tree: splits by info gain / Ginihigh variance; prune / ensemble.
// metrics & impurityevaluation
accuracy=(TP+TN)/allmisleading on imbalance.
precision=TP/(TP+FP) · recall=TP/(TP+FN)F1=2PR/(P+R).
entropy=−Σp log p · Gini=1−Σp²tree split criteria.
info gain = entropy(parent)−Σ weighted child entropypick max gain split.
// bias-variance & cross-validationcore concept
error = bias² + variance + irreducible noisethe decomposition.
high bias = underfit (too simple)train & test both bad.
high variance = overfit (too complex)train good, test bad.
k-fold CV: split k parts, train k−1 test 1, avgrobust estimate.
LOO CV = n-fold (k=n)low bias, high variance, costly.
regularization ↑ → bias ↑, variance ↓the trade-off knob.
// neural networksMLP / FFN
perceptron: step(w·x+b); linear onlycan't solve XOR.
MLP: hidden layers + nonlinear activationuniversal approximator.
activations: sigmoid, tanh, ReLU=max(0,x)ReLU avoids vanishing gradient.
training: forward pass → loss → backprop (chain rule) → gradient descentw ← w − η·∂L/∂w.
// unsupervisedno labels
k-means: assign to nearest centroid, update means, repeatminimizes within-cluster SS; pick k.
k-medoid: centers are actual pointsrobust to outliers (vs k-means).
hierarchical: agglomerative (bottom-up) / divisive (top-down)dendrogram.
linkage: single (min dist), complete (max), averagesingle → chaining.
PCA: project onto top eigenvectors of covariancemax variance directions; = SVD of centered data.
explained variance = λᵢ / Σλpick components by cumulative variance.

exam traps

  • High bias = underfit, high variance = overfit — and regularization (ridge/λ) trades variance for bias. Most-tested concept.
  • Accuracy lies on imbalanced data — use precision/recall/F1.
  • kNN: small k overfits, large k underfits; it's lazy (no training cost, expensive prediction).
  • Naïve Bayes assumes feature independence — that's the "naïve" part.
  • PCA needs centered (often scaled) data and uses covariance eigenvectors; components are orthogonal, ordered by variance.
  • Single-linkage clustering chains; complete-linkage makes compact clusters — know the difference.
  • Perceptron can't do XOR (not linearly separable) — needs a hidden layer.
  • For each method know: idea, when it applies, key formula, failure mode. That's how questions are framed.
  • Bias-variance + cross-validation and PCA are the highest-frequency conceptual topics — links to Linear Algebra (eigen/SVD).
  • Memorize precision/recall/F1, entropy/Gini/info-gain, and the k-means loop — frequent NAT/MCQ.
  • ML + Prob/Stats + Linear Algebra together are the bulk of DA marks — your AIR-1 core.
