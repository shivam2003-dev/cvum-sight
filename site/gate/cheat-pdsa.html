// how to use this

Complexities and behaviours for GATE DA PDSA: data structure operations, search, the basic sorts, divide-and-conquer, and graph traversals/shortest path — all the time/space bounds you must recall instantly, plus the Master theorem for recurrences. Most questions reduce to "state the complexity" or "trace the algorithm".

// data structure operations (avg)O(·)
array: access O(1), search O(n), insert O(n)contiguous.
stack/queue: push/pop/enqueue/dequeue O(1)LIFO / FIFO.
linked list: access O(n), insert@known O(1)no random access.
hash table: search/insert/del O(1) avg, O(n) worstworst = all collide.
BST (balanced): search/insert/del O(log n)O(n) if skewed.
binary heap: insert/extract O(log n), peek O(1)build-heap O(n).
// searchlinear vs binary
linear search: O(n)unsorted ok.
binary search: O(log n)requires SORTED array.
recurrence T(n)=T(n/2)+O(1)→ O(log n).
// sortingbest / avg / worst
bubble / insertion / selectionO(n²) avg/worst; insertion O(n) best (nearly sorted).
merge sort: O(n log n) all casesstable; O(n) extra space.
quicksort: O(n log n) avg, O(n²) worstworst = bad pivot/sorted; in-place.
heap sort: O(n log n) all casesin-place, not stable.
comparison sort lower bound: Ω(n log n)can't beat by comparisons.
stable: bubble, insertion, mergeNOT: selection, quick, heap.
// divide & conquer / Master theoremrecurrences
T(n)=aT(n/b)+f(n), compare f(n) vs n^(log_b a)Master theorem.
f smaller → Θ(n^log_b a)case 1.
f = Θ(n^log_b a) → Θ(n^log_b a·log n)case 2 (merge/quick: 2T(n/2)+n → n log n).
f larger (regularity) → Θ(f(n))case 3.
// graphs: traversal & shortest pathV vertices, E edges
BFS / DFS: O(V+E)adjacency list; BFS=queue, DFS=stack/recursion.
BFS gives shortest path in UNWEIGHTED graphfewest edges.
Dijkstra: O((V+E)log V) with heapnon-negative weights only.
Bellman-Ford: O(VE)handles negative edges; detects neg cycles.
topological sort: DAG only, O(V+E)DFS finish-time or Kahn's.
adjacency matrix O(V²) space; list O(V+E)dense vs sparse.
// Python & complexity notesquick facts
list append O(1) amortized, insert(0,x) O(n)dynamic array.
dict / set: O(1) avg lookuphash-based.
x in list O(n) · x in set O(1)common trap.
O(1)<O(log n)<O(n)<O(n log n)<O(n²)<O(2ⁿ)growth order.

exam traps

  • Binary search needs a sorted array — applying it to unsorted data is wrong.
  • Quicksort worst case O(n²) on sorted/reverse input with naive pivot; merge/heap stay O(n log n).
  • Stability: bubble/insertion/merge stable; selection/quick/heap not. Frequently asked.
  • Dijkstra fails with negative edges — use Bellman-Ford.
  • BFS = shortest path only for unweighted graphs; weighted needs Dijkstra/Bellman-Ford.
  • Hash worst case O(n) (all collisions), not O(1) — the average is O(1).
  • Memorize the operation-complexity table and the sort best/avg/worst + stability grid — pure recall marks.
  • Recurrences → Master theorem (merge/quick = case 2 = n log n).
  • Graph questions: pick the algorithm by weights (unweighted→BFS, non-neg→Dijkstra, negative→Bellman-Ford) and state O(V+E).
  • Trace-the-algorithm questions: do them on paper, slowly — accuracy over speed.
