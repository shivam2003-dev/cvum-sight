// how to use this

Every formula and result for GATE DA Probability & Statistics on one page — memorize the boxes cold. Grouped by topic: counting, core probability, Bayes, expectation/variance, distributions (with E & Var), inference (CLT, CI, tests). The deep "learn + how to solve" version is the full subject page; this is the exam-morning recall sheet.

// countingorder?
nPr = n!/(n−r)!permutation — order matters (seats).
nCr = n!/(r!(n−r)!)combination — order doesn't (team).
with repetition: nʳr picks from n, reusable (PINs).
AND → × · OR(disjoint) → +multiplication / addition rule.
// core probabilityaxioms → results
P(Aᶜ)=1−P(A)complement.
P(A∪B)=P(A)+P(B)−P(A∩B)inclusion–exclusion.
P(A|B)=P(A∩B)/P(B)conditional (shrink world to B).
P(A∩B)=P(A|B)P(B)chain / multiplication rule.
indep: P(A∩B)=P(A)P(B)⇔ P(A|B)=P(A). NOT exclusive.
mut. excl: P(A∩B)=0→ P(A∪B)=P(A)+P(B).
// Bayes & total probabilitymost tested
P(B)=Σ P(B|Aᵢ)P(Aᵢ)total probability (the denominator).
P(Aⱼ|B)=P(B|Aⱼ)P(Aⱼ) / P(B)posterior = likelihood×prior / evidence.
tree: multiply branch ÷ Σ branches→Bfastest, fewest errors.
// random variablesdiscrete vs continuous
discrete: Σ p(x)=1, p(x)=P(X=x)PMF.
continuous: ∫f(x)dx=1, P(X=x)=0PDF; f can exceed 1.
F(x)=P(X≤x), f=F′CDF (works for both).
find const: ∫f=1 · median: F(m)=.5standard tasks.
// expectation & varianceworkhorse
E[X]=Σx·p(x) or ∫x·f(x)dxmean / balance point.
Var(X)=E[X²]−(E[X])²use 90% of the time.
E[aX+b]=aE[X]+blinearity.
E[X+Y]=E[X]+E[Y] ALWAYSeven if dependent.
Var(aX+b)=a²Var(X)b drops out.
indep → Var(X+Y)=Var X+Var Yelse add 2Cov(X,Y).
Cov=E[XY]−E[X]E[Y] · ρ=Cov/(σₓσᵧ)−1≤ρ≤1; ρ catches linear only.
E[X]=E[E[X|Y]] · Var=E[Var(X|Y)]+Var(E[X|Y])total expectation / variance.
// distributions (E, Var)memorize

discrete

Bernoulli(p)E=p, Var=p(1−p).
Binomial(n,p): P=nCk pᵏ(1−p)ⁿ⁻ᵏE=np, Var=np(1−p).
Poisson(λ): P=e⁻λλᵏ/k!E=Var=λ (rare counts).
Geometric(p)E=1/p; memoryless (discrete).

continuous

Uniform(a,b)E=(a+b)/2, Var=(b−a)²/12.
Exponential(λ): f=λe⁻λˣE=1/λ, Var=1/λ²; memoryless.
Normal(μ,σ²)68/95/99.7 within 1/2/3σ.
Z=(X−μ)/σ → Φ(z)standardize; Φ(−z)=1−Φ(z).
// inference: CLT, CI, testsone recipe
X̄ ~ N(μ, σ²/n) · SE=σ/√nCLT (sample MEAN; SE~1/√n).
CI = X̄ ± z*·SE95%→1.96, 99%→2.58; t* if σ unknown.
z=(X̄−μ₀)/(σ/√n)σ known / large n.
t=(X̄−μ₀)/(s/√n), df=n−1σ unknown, small n.
χ²=Σ(Oᵢ−Eᵢ)²/Eᵢvariance / goodness-of-fit / independence.
|stat|>crit (or p<α) → reject H₀mind 1-tail vs 2-tail.
z*: 1.645(90) 1.96(95) 2.33(98) 2.58(99)key criticals.

exam traps

  • Mutually exclusive ≠ independent — exclusive (nonzero prob) ⇒ dependent.
  • Forgetting Bayes denominator — always P(B) by total probability.
  • Continuous P(X=x)=0; PDF f can exceed 1; ≤ vs < only matters for discrete.
  • Cov=0 ⇏ independent — only rules out linear relation.
  • Var adds only if independent; E always adds.
  • CLT = sample mean, not individual data; SE shrinks like 1/√n.
  • Type I (α)=false alarm, Type II (β)=miss; can't shrink both.
  • Recall the E/Var table instantly — cheapest marks in the paper.
  • Var=E[X²]−(E[X])² and Bayes by tree are your two most-used tools.
  • One test recipe: (estimate−null)/SE vs critical — z/t/χ² differ only in the statistic.
  • Win the conceptual one-markers (exclusive/independent, Cov vs independence, CI meaning).
