Linear Algebra — learn & intuition.

// what this page is

The geometry behind every linear-algebra formula — what a matrix actually does to space — plus a how-to-solve recipe per GATE question type with worked examples. Read once; then the cheatsheet is your recall sheet. This is a top-weight, high-return subject: almost pure recall + plug-in once the pictures click.

One sentence unlocks the whole subject: a matrix is a function that transforms space — it stretches, rotates, shears, flattens. Its columns tell you where the basis vectors land. Rank, determinant, eigenvectors, and SVD are all just different ways of describing how it moves space.

01 A matrix is a transformation

key ideaMultiplying A·x sends the vector x to a new place. The columns of A are where the unit basis vectors land. Want to know what A does? Look at its columns — that's the whole map.

So matrix multiplication AB means "do B's transformation, then A's" (right to left). This is why it isn't commutative: rotating then stretching ≠ stretching then rotating.

02 Linear independence, span & basis

think of it likeA set of vectors is linearly independent if none is a redundant combination of the others — each adds a genuinely new direction. Span = every point you can reach by combining them. A basis is the minimum independent set whose span is the whole space — no waste, no gaps.
  • Vectors are independent ⇔ the only combination giving the zero vector is all-zero coefficients.
  • Dimension = size of any basis = number of independent directions.

How to test independence

  1. Stack the vectors as rows (or columns) of a matrix.
  2. Row-reduce. Count non-zero rows = rank.
  3. rank = number of vectors → independent. rank < count → dependent.

03 Rank & nullity — the central count

key ideaRank = the number of genuinely independent directions in A's output — the dimension of the space A squashes everything into. Nullity = the dimension of the directions A crushes to zero.

The Rank–Nullity theorem ties them together: rank(A) + nullity(A) = n (number of columns). Every input dimension either survives (rank) or gets collapsed (nullity).

  • rank = number of pivots after row reduction = number of non-zero rows in REF.
  • nullity = number of free variables = dimension of the null space {x : Ax=0}.
workedA is 3×4 with rank 2 → nullity = 4−2 = 2. The system Ax=0 has 2 free variables → infinitely many solutions forming a 2-D plane through the origin.

04 Solving Ax = b — how many solutions?

The universal solvability test (compare rank of A to rank of augmented [A|b])

  1. rank(A) < rank([A|b]) → no solution (inconsistent).
  2. rank(A) = rank([A|b]) = n (cols) → unique solution.
  3. rank(A) = rank([A|b]) < n → infinitely many (n − rank free variables).

For the homogeneous case Ax=0: always consistent (x=0 works). It has a non-trivial solution ⇔ rank < n ⇔ columns dependent ⇔ (if square) det A = 0.

05 Determinant — the volume scale factor

think of it likeThe determinant is the factor by which A scales area/volume. det=2 doubles volume; det=0 flattens space into a lower dimension (so it's non-invertible); a negative det flips orientation (a mirror).
  • det A = 0 ⇔ A is singular ⇔ columns dependent ⇔ rank < n ⇔ 0 is an eigenvalue ⇔ Ax=0 has non-trivial solutions. Learn this chain — it's the heart of the subject.
  • det(AB)=det A·det B; det(AT)=det A; det(A−1)=1/det A; det(kA)=kndet A for n×n.
  • Triangular matrix → det = product of the diagonal.

06 Eigenvalues & eigenvectors — the soul of the subject

key ideaAn eigenvector is a special direction that A does not rotate — it only stretches it. The stretch factor is the eigenvalue λ: Ax = λx. These are the "natural axes" of the transformation.

How to find eigenvalues & eigenvectors

  1. Solve the characteristic equation det(A − λI) = 0 → the eigenvalues λ.
  2. For each λ, solve (A − λI)x = 0 → the eigenvector(s).

The two shortcuts GATE loves (skip the full polynomial when possible):

  • Σλi = trace(A) (sum of diagonal).
  • Πλi = det(A).
worked — 2×2 in secondsA=[[2,1],[1,2]]. trace=4, det=3. So λ₁+λ₂=4, λ₁λ₂=3 → λ=1 and 3. No polynomial needed.

Eigenvalue facts that turn into one-markers:

  • Eigenvalues of Ak are λk; of A−1 are 1/λ; of A+cI are λ+c. (Eigenvectors unchanged.)
  • Triangular/diagonal matrix → eigenvalues are the diagonal entries.
  • Symmetric real matrix → eigenvalues are real and eigenvectors orthogonal.

Fig — eigenvectors keep their direction under A; everything else gets rotated.

07 Special matrices — recognize & recall

  • Symmetric (A=AT) — real eigenvalues, orthogonal eigenvectors, always diagonalizable.
  • Orthogonal (ATA=I, so A−1=AT) — rotation/reflection; preserves length; |λ|=1; det=±1.
  • Idempotent (A²=A) — a projection; eigenvalues are 0 or 1.
  • Positive-definite — symmetric with all eigenvalues > 0; xTAx > 0 for x≠0. (Covariance matrices, Hessians at minima.)
  • Nilpotent (Ak=0) — all eigenvalues 0.
the catchGATE asks "which property holds": map the defining equation to the eigenvalue consequence. Idempotent→{0,1}, orthogonal→|λ|=1, positive-definite→all λ>0. Memorize the eigenvalue signature of each.

08 Quadratic forms & definiteness

A quadratic form is Q(x)=xTAx with A symmetric. Its definiteness = the sign pattern of A's eigenvalues:

  • all λ > 0 → positive definite (bowl opening up, unique minimum).
  • all λ < 0 → negative definite.
  • mixed signs → indefinite (saddle).
why it mattersThis is the link to optimization: the Hessian's definiteness tells you whether a critical point is a min, max, or saddle.

09 Decompositions — LU & SVD

  • LU — factor A = L·U (lower × upper triangular). It's Gaussian elimination stored as matrices; makes solving Ax=b and finding det cheap (det = product of U's diagonal).
  • SVD — A = UΣVT works for any matrix (even non-square). U, V are orthogonal; Σ holds the singular values σi = √(eigenvalues of ATA), all ≥ 0.
key ideaSVD says every linear map is rotate → scale → rotate. The singular values are the scale factors along the principal axes. The number of non-zero singular values = rank. SVD underpins PCA in machine learning and low-rank approximation.

10 The master decision tree

Read the question → branch

  1. "How many solutions / is it consistent" → compare rank(A) vs rank([A|b]) (§04).
  2. "Independent? / dimension? / rank?" → row-reduce, count pivots (§02–03).
  3. "Eigenvalues" → trace & det shortcuts first, else det(A−λI)=0 (§06).
  4. "Invertible? singular?" → check det=0 chain (§05).
  5. "min/max/saddle, definiteness" → eigenvalue signs of the symmetric matrix (§08).
  6. "Property of this matrix" → match defining equation to eigenvalue signature (§07).

11 The high-frequency exam traps

memorize these

  • det=0 ⇔ singular ⇔ rank<n ⇔ 0 is an eigenvalue ⇔ dependent columns — the master equivalence chain.
  • Σλ=trace, Πλ=det — use before grinding the characteristic polynomial.
  • Eigenvalues of A−1 are 1/λ, of Ak are λk, of A+cI are λ+c — eigenvectors unchanged.
  • Symmetric ⇒ real eigenvalues + orthogonal eigenvectors.
  • Orthogonal: A−1=AT, |λ|=1, det=±1.
  • Rank–Nullity: rank + nullity = #columns (not rows).
  • AB ≠ BA in general; but trace(AB)=trace(BA).
  • Singular values are √eig(ATA), always ≥ 0, even when eigenvalues are negative or complex.

12 FAQ

Eigenvalues vs singular values — what's the difference?

Eigenvalues need a square matrix and can be negative/complex (Ax=λx). Singular values exist for any matrix, are always ≥0, and equal √(eigenvalues of ATA). For a symmetric positive-definite matrix they coincide.

When is a matrix diagonalizable?

When it has n linearly independent eigenvectors. Guaranteed if all n eigenvalues are distinct, or if the matrix is symmetric. It can fail when an eigenvalue is repeated but doesn't have enough independent eigenvectors (defective matrix).

Fastest way to get 2×2 eigenvalues?

Use λ₁+λ₂=trace and λ₁λ₂=det. Solve λ²−(trace)λ+det=0 mentally. Don't expand det(A−λI) by hand unless it's 3×3+.

How do I read rank off quickly?

Row-reduce to echelon form; rank = number of non-zero rows (pivots). For a square matrix, full rank ⇔ det≠0 ⇔ invertible.

  • A matrix transforms space; its columns show where the basis lands.
  • The det=0 equivalence chain connects rank, invertibility, eigenvalues, and solvability — know it cold.
  • trace & det shortcuts get eigenvalues in seconds; eigenvalue facts generate easy one-markers.
  • Recognize special matrices by their eigenvalue signature; that's most of the recall marks.
