// what this page is

When each model applies and why, the bias-variance trade-off, how PCA falls out of eigenvectors, and how to compute every metric — with worked examples. One of the heaviest-weight DA subjects; bias-variance/cross-validation and PCA are the highest-frequency topics. Pair with the cheatsheet; it leans on Linear Algebra and Prob/Stats.

Machine learning fits a function to data so it generalizes to new data. Every method is a different answer to "what shape of function, and how do we stop it from just memorizing?" Keep two ideas central — the bias-variance trade-off (under- vs over-fitting) and the geometry of the decision boundary — and the model zoo organizes itself.

01 The learning setup

key ideaSupervised = labelled data, learn input→output (regression for numbers, classification for categories). Unsupervised = no labels, find structure (clustering, dimensionality reduction). We minimize a loss on training data but care about error on unseen data.

02 Bias-variance — the most-tested idea

think of it likeArchery. Bias = your shots cluster but off the bullseye (model too simple, underfits). Variance = shots scatter wildly around the target (model too complex, overfits, memorizes noise). Total error = bias² + variance + irreducible noise. You can't kill both — pushing one down lifts the other.

Fig — total test error is U-shaped; the minimum is the right complexity.

the catchHigh training accuracy + low test accuracy = overfitting (high variance). Fix with more data, regularization (ridge/lasso), simpler models. Both low = underfitting (high bias) → richer model/features. GATE asks you to diagnose from the train/test gap.

03 Cross-validation & regularization

  • k-fold CV — split data into k parts, train on k−1, test on the held-out part, rotate, average. Gives an honest generalization estimate without wasting data.
  • Regularization adds a penalty on weight size to fight overfitting. Ridge (L2) shrinks weights smoothly; Lasso (L1) drives some weights to exactly 0 (feature selection).

04 Regression

  • Linear regression — fit y = w·x + b minimizing squared error (least squares). Closed form w = (XᵀX)⁻¹Xᵀy — a Linear Algebra result.
  • Ridge — least squares + λ‖w‖² penalty; handles multicollinearity, reduces variance.
  • Logistic regression — despite the name, classification: pushes a linear score through the sigmoid to get a probability, thresholded at 0.5.
the catchLogistic regression is classification, not regression. It models P(y=1|x) with the sigmoid and is trained by maximizing likelihood (cross-entropy loss), not squared error.

05 The classifier zoo — when each applies

  • kNN — classify by majority vote of the k nearest training points. No training, lazy; sensitive to feature scaling and k. Small k → high variance; large k → high bias.
  • Naïve Bayes — apply Bayes assuming features are conditionally independent given the class. Fast, great for text; the independence assumption is "naïve" but works.
  • LDA — assumes each class is Gaussian with shared covariance; gives a linear boundary.
  • SVM — find the hyperplane with the maximum margin between classes; support vectors are the closest points. The kernel trick handles non-linear boundaries by an implicit high-dim mapping.
  • Decision tree — recursively split on the feature that most reduces impurity. Interpretable but overfits; fixed by pruning or ensembling (random forest).
  • Neural net — layers of weighted sums + non-linear activations; trained by backprop (gradient descent on the loss).

How to pick / reason about a model

  1. Need a probability + fast + text → Naïve Bayes / logistic.
  2. Non-linear boundary, medium data → SVM with kernel.
  3. Interpretability → decision tree.
  4. Local structure, few features → kNN.

06 Decision-tree splitting — entropy & Gini

key ideaA tree splits on whichever feature makes the children purest. Impurity is measured by entropy H = −Σ pᵢ log₂ pᵢ or Gini 1 − Σ pᵢ². Information gain = parent impurity − weighted child impurity; pick the split that maximizes it.
workedNode with 50/50 classes: entropy = −0.5log₂0.5 −0.5log₂0.5 = 1 bit (max impurity). All one class: entropy = 0 (pure). A split that sends all positives left, negatives right → child entropy 0 → maximal information gain.

07 Evaluation metrics

confusion matrixTP, FP, FN, TN. Precision = TP/(TP+FP) ("of those I flagged, how many right"). Recall = TP/(TP+FN) ("of the real positives, how many I caught"). F1 = 2·P·R/(P+R) (harmonic mean). Accuracy = (TP+TN)/all.
the catchAccuracy lies on imbalanced data. 99% negatives → predicting "always negative" scores 99% accuracy yet catches zero positives. Use precision/recall/F1. Precision vs recall is a trade-off set by the threshold.

08 Unsupervised — clustering

  • k-means — alternate: assign each point to the nearest centroid, then recompute centroids as cluster means. Minimizes within-cluster variance. Must choose k; sensitive to initialization; assumes round clusters.
  • k-medoids — like k-means but centers are actual data points → robust to outliers.
  • Hierarchical — build a tree of merges (agglomerative) or splits; cut it to get clusters; no preset k.

09 PCA — the second-most-tested topic

key ideaPCA finds the directions of maximum variance in the data and projects onto the top few — compressing dimensions while keeping the most information. Those directions are exactly the eigenvectors of the covariance matrix; each eigenvalue is the variance captured along its axis.

How to do PCA

  1. Center the data (subtract the mean of each feature).
  2. Compute the covariance matrix.
  3. Find its eigenvalues & eigenvectors.
  4. Sort eigenvectors by eigenvalue (descending); the top k are the principal components.
  5. Variance explained by component i = λᵢ / Σλ.
workedCovariance eigenvalues 6, 3, 1. First component explains 6/(6+3+1)=60% of variance; first two explain 90% → drop the third axis, lose only 10%.
the catchAlways standardize before PCA when features are on different scales — otherwise the largest-unit feature dominates. PCA components are orthogonal and ordered by variance, not by predictive usefulness.

10 The master decision tree

Read the question → branch

  1. "Overfit/underfit? what to do" → bias-variance from train/test gap (§02–03).
  2. "Compute precision/recall/F1/accuracy" → confusion matrix (§07).
  3. "Best split / information gain" → entropy or Gini (§06).
  4. "Variance explained / reduce dimensions" → PCA via eigenvalues (§09).
  5. "Which model / property of model" → §04–05 reasoning.

11 The high-frequency exam traps

memorize these

  • Overfit = high variance (big train-test gap); underfit = high bias (both poor).
  • Logistic regression is classification (sigmoid, cross-entropy).
  • Accuracy misleads on imbalance → use precision/recall/F1.
  • PCA = eigenvectors of covariance; variance explained = λᵢ/Σλ; standardize first.
  • kNN & k-means need feature scaling; small k → variance, large k → bias.
  • L1(lasso) zeros weights (selection); L2(ridge) shrinks smoothly.
  • SVM maximizes the margin; support vectors are the closest points.
  • Entropy max at 50/50 (=1 bit), 0 when pure.

12 FAQ

How do I tell overfitting from underfitting?

Compare train vs test error. Large gap (train good, test bad) = overfit/high variance. Both bad = underfit/high bias. Both good = you're at the sweet spot.

Entropy or Gini for tree splits — does it matter?

Rarely changes the chosen split. Both measure impurity; Gini is cheaper (no log). GATE may ask you to compute either, so know both formulas.

Why is Naïve Bayes "naïve"?

It assumes features are independent given the class, which is usually false — yet the classifier still performs well because it only needs the right argmax, not exact probabilities.

Precision vs recall — which to optimize?

Depends on cost. Spam filter: precision (don't junk real mail). Disease screening: recall (don't miss sick patients). F1 balances both; the threshold slides between them.

  • Center everything on bias-variance — it explains regularization, CV, model choice, and the train/test gap.
  • PCA = top eigenvectors of covariance; variance explained = λᵢ/Σλ. Highest-value recall after bias-variance.
  • Know precision/recall/F1 from a confusion matrix; accuracy lies under imbalance.
  • Logistic = classification; L1 selects, L2 shrinks; SVM maximizes margin; entropy/Gini drive splits.
