AWS — The Associate Certification Cheatsheet.

aws cloud associate-cert interview-prep
For the AWS Associate certs (SAA / Developer / SysOps). Know the core services, what each is for, and the VPC + IAM fundamentals — most questions reduce to "right service for the job" and "least privilege networking".

Global infrastructure

  • Region — geographic area (us-east-1). Pick for latency, price, compliance.
  • Availability Zone (AZ) — isolated datacenter(s) in a region. Deploy across ≥2 AZs for HA.
  • Edge location — CloudFront CDN PoP.

IAM

ThingWhat
UserA person/long-lived identity.
GroupCollection of users, attach policies.
RoleAssumable identity for services/cross-account (no long-lived keys). Prefer this.
PolicyJSON of allow/deny on actions/resources.
roles over keys Give EC2/Lambda an IAM role, never hard-coded access keys. Least privilege; explicit deny always wins.

Compute

  • EC2 — virtual machines. Types: on-demand, reserved, spot (cheap, interruptible), savings plans.
  • Lambda — serverless functions, pay per invocation, event-driven.
  • ECS/EKS/Fargate — containers (Fargate = serverless containers).
  • Auto Scaling Group — scale EC2 on demand; ELB spreads traffic.

VPC & networking

ComponentRole
VPCYour private network (a CIDR block).
SubnetSlice of the VPC in one AZ. Public (route to IGW) or private.
Internet GatewayVPC ↔ internet for public subnets.
NAT GatewayPrivate subnets → internet (outbound only).
Security GroupStateful firewall on the instance (allow rules).
NACLStateless firewall on the subnet (allow + deny).
SG vs NACL Security Group = stateful (return traffic auto-allowed), instance-level, allow-only. NACL = stateless (must allow both directions), subnet-level, allow + deny. Classic exam question.

Storage

  • S3 — object storage, 11 9s durability. Classes: Standard, IA, Glacier (archive). Versioning, lifecycle, encryption.
  • EBS — block volume for one EC2 (like a disk), AZ-bound.
  • EFS — shared NFS across many instances/AZs.
  • Instance store — ephemeral, lost on stop.

Databases

  • RDS — managed relational (Postgres/MySQL/...). Multi-AZ = HA failover; read replicas = scale reads.
  • Aurora — AWS's cloud-native MySQL/Postgres, faster + auto-scaling storage.
  • DynamoDB — managed NoSQL key-value, single-digit-ms, serverless.
  • ElastiCache — managed Redis/Memcached.

Monitoring & messaging

  • CloudWatch — metrics, logs, alarms, dashboards.
  • CloudTrail — API audit log (who did what).
  • SQS (queue), SNS (pub/sub), EventBridge (event bus).
  • Route 53 (DNS), CloudFront (CDN).

Rapid-fire Q&A

  • Security Group vs NACL?SG: stateful, instance-level, allow-only. NACL: stateless, subnet-level, allow + deny.
  • Public vs private subnet?Public has a route to an Internet Gateway; private reaches out via a NAT Gateway (outbound only).
  • Multi-AZ vs read replica (RDS)?Multi-AZ = sync standby for HA/failover (not for reads). Read replica = async, scales reads.
  • S3 vs EBS vs EFS?S3 = object store (API). EBS = block disk for one EC2. EFS = shared filesystem across many.
  • When Lambda vs EC2?Lambda for short, event-driven, bursty work (no servers). EC2 for long-running/full control.
  • How should EC2 get S3 access?Attach an IAM role to the instance — never embed access keys.
  • Spot vs on-demand vs reserved?Spot = cheapest, can be reclaimed. On-demand = flexible, pricey. Reserved/Savings = commit for discount.
