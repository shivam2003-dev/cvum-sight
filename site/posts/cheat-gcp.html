GCP — The Associate Certification Cheatsheet.

gcp cloud associate-cert interview-prep
For the Google Associate Cloud Engineer cert. Know the resource hierarchy, IAM, the core compute options (and when to use each), VPC, and the storage/database menu. Many questions are "pick the right product".

Resource hierarchy

Organization → Folder → Project → Resources. The Project is the core billing + isolation unit; everything lives in one. IAM policies inherit down the tree.

IAM

ThingWhat
MemberUser, group, or service account.
RoleBundle of permissions: basic (owner/editor/viewer), predefined, custom.
Bindingmember + role on a resource.
Service accountIdentity for workloads (like an AWS role). Prefer over keys.
prefer predefined roles Avoid the broad basic roles (owner/editor) in prod — use predefined/custom roles for least privilege. Attach a service account to the VM/workload, don't ship keys.

Compute — pick the right one

  • Compute Engine — VMs (IaaS). Full control. Preemptible/Spot = cheap.
  • GKE — managed Kubernetes (containers at scale).
  • Cloud Run — serverless containers, scale to zero, request-driven.
  • Cloud Functions — serverless functions, event-driven.
  • App Engine — managed PaaS for apps.

Rule of thumb: VM control → Compute Engine; containers + orchestration → GKE; stateless container, no infra → Cloud Run; small event glue → Cloud Functions.

Networking (VPC)

  • VPC is global; subnets are regional (unlike AWS where VPC is regional).
  • Firewall rules — VPC-level, stateful, allow/deny by tags/service accounts.
  • Cloud Load Balancing — global (HTTP(S)) or regional.
  • Cloud NAT — egress for private instances; Cloud DNS — managed DNS.

Storage

  • Cloud Storage (GCS) — object storage. Classes: Standard, Nearline, Coldline, Archive.
  • Persistent Disk — block storage for VMs.
  • Filestore — managed NFS.

Operations & data

  • Cloud Logging / Monitoring (the old Stackdriver) — logs, metrics, alerts, dashboards.
  • Pub/Sub — global messaging / event ingestion.
  • gcloud CLI, gsutil (GCS), kubectl (GKE).

Rapid-fire Q&A

  • Resource hierarchy?Organization → Folder → Project → Resources. IAM inherits down. Project = billing/isolation unit.
  • Cloud Run vs GKE vs Compute Engine?Cloud Run = serverless containers (scale to zero). GKE = managed K8s. Compute Engine = raw VMs.
  • VPC scope vs AWS?GCP VPC is global, subnets regional. AWS VPC is regional.
  • Cloud SQL vs Spanner vs Bigtable?Cloud SQL = managed relational; Spanner = global horizontally-scaling relational; Bigtable = wide-column at massive scale.
  • How should a VM authenticate to services?Attach a service account with least-privilege roles — not key files.
  • BigQuery is for?Serverless analytics / data warehouse — SQL over huge datasets, not OLTP.
  • Basic vs predefined vs custom roles?Basic = broad (owner/editor/viewer, avoid in prod); predefined = service-scoped; custom = your exact permission set.
