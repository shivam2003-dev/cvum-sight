GCP — The Associate Certification Cheatsheet.

gcp cloud associate-cert interview-prep
For the Google Associate Cloud Engineer cert. Know the resource hierarchy, IAM, the compute options (and when each fits), VPC (global!), and the storage/database menu. Many questions are "pick the right product" and "least-privilege IAM".

1. Resource hierarchy

Organization → Folder → Project → Resources. The Project is the core unit of billing, quota, and isolation — every resource lives in exactly one. IAM policies + org policies inherit downward. Use folders to model departments/environments.

2. IAM

ThingWhat
MemberUser, group, domain, or service account.
RoleBundle of permissions: basic (owner/editor/viewer — avoid), predefined (per-service), custom.
Bindingmember + role on a resource (the IAM policy).
Service accountIdentity for workloads (like an AWS role). Prefer over keys.
avoid basic roles + key files The basic roles (owner/editor/viewer) are too broad for prod — use predefined/custom for least privilege. Attach a service account to the VM/workload; don't download and ship SA key files.

3. Compute — pick the right one

ServiceUse when
Compute EngineVMs (IaaS). Full control. Preemptible/Spot = cheap; managed instance groups + autoscaling.
GKEManaged Kubernetes — containers at scale, orchestration.
Cloud RunServerless containers, scale to zero, request-driven, any language.
Cloud FunctionsServerless functions, event-driven glue.
App EngineManaged PaaS (standard/flexible).

Rule of thumb: VM control → Compute Engine; containers + orchestration → GKE; stateless container, no infra → Cloud Run; small event glue → Cloud Functions.

4. Networking (VPC)

  • VPC is global; subnets are regional (unlike AWS where the VPC is regional) — a single VPC spans all regions.
  • Firewall rules — VPC-level, stateful, by network tags or service accounts; priority-ordered.
  • Cloud Load Balancing — global (HTTP(S), anycast IP) or regional (TCP/UDP/internal).
  • Cloud NAT — egress for private instances (no public IP); Cloud DNS — managed DNS.
  • VPC peering / Shared VPC / Interconnect/VPN — connect networks / on-prem.
  • Private Google Access / Private Service Connect — reach Google APIs privately.

5. Storage

ServiceType / use
Cloud Storage (GCS)Object storage. Classes: Standard, Nearline, Coldline, Archive (lifecycle + versioning).
Persistent DiskBlock storage for VMs (zonal/regional). Snapshots.
FilestoreManaged NFS (shared).
Local SSDEphemeral high-IOPS, lost on stop.

6. Databases — pick the right one

NeedProduct
Managed relational (MySQL/Postgres/SQL Server)Cloud SQL
Global, horizontally-scaling relationalCloud Spanner
Serverless NoSQL documentFirestore
Wide-column, huge scale / time-seriesBigtable
Analytics / data warehouseBigQuery (serverless SQL)
In-memory cacheMemorystore (Redis/Memcached)

7. Data & messaging

  • Pub/Sub — global messaging / event ingestion (at-least-once).
  • Dataflow — managed Apache Beam stream/batch processing.
  • Dataproc — managed Spark/Hadoop.
  • Composer — managed Airflow orchestration.
  • BigQuery — serverless warehouse; SQL over huge datasets (analytics, not OLTP).

8. Operations & security

  • Cloud Logging / Monitoring (ex-Stackdriver) — logs, metrics, alerts, dashboards, uptime checks.
  • Cloud Trace / Profiler / Error Reporting — performance + errors.
  • IAM + Org Policies — guardrails; KMS — keys; Secret Manager — secrets.
  • Cloud Armor — WAF/DDoS; VPC Service Controls — data exfil perimeter.
  • Billing — budgets + alerts; labels for cost attribution.

10. Rapid-fire interview Q&A

  • Resource hierarchy?Organization → Folder → Project → Resources. IAM/org policies inherit down. Project = billing/quota/isolation unit.
  • Cloud Run vs GKE vs Compute Engine?Cloud Run = serverless containers (scale to zero). GKE = managed Kubernetes. Compute Engine = raw VMs (full control).
  • VPC scope vs AWS?GCP VPC is global; subnets are regional. AWS VPC is regional.
  • Cloud SQL vs Spanner vs Bigtable?Cloud SQL = managed relational; Spanner = global horizontally-scaling relational (strong consistency); Bigtable = wide-column at massive scale / time-series.
  • How should a VM authenticate to services?Attach a service account with least-privilege roles — not downloaded key files.
  • What is BigQuery for?Serverless analytics / data warehouse — SQL over huge datasets. Not for OLTP/transactions.
  • Basic vs predefined vs custom roles?Basic = broad (owner/editor/viewer, avoid in prod); predefined = service-scoped; custom = exact permission set.
  • Firestore vs Bigtable?Firestore = serverless document DB (app data, queries, real-time). Bigtable = wide-column, huge throughput, key-based (analytics/IoT/time-series).
  • Pub/Sub use?Decoupled, global, at-least-once messaging / event ingestion; fan-out to subscribers.
  • How to reach Google APIs without public IP?Private Google Access / Private Service Connect; egress via Cloud NAT for general internet.
  • GCS storage classes?Standard (hot) → Nearline → Coldline → Archive (coldest/cheapest). Lifecycle rules transition objects.
  • How do you scope cost?Per-project billing + budgets/alerts; labels for attribution across projects.
