Chapter 3 — Finite Markov Decision Processes, explained.

mdpreturnbellman-equationpolicyvalue-function

// the one-minute version

The mathematical language of sequential decisions: states, actions, rewards, returns, policies, value functions, and Bellman equations.

A bandit forgets the past after every pull. Real decisions change what happens next. Taking a shortcut changes your location, risk, fuel, and future choices. Markov decision processes describe this chain of consequences.

01 The chapter in one mental model

core loopvπ(s) = Σₐ π(a|s) Σₛ′,ᵣ p(s′,r|s,a)[r + γvπ(s′)].

The notation can look dense, but the purpose is practical: turn experience into a better prediction or a better decision. Read every equation by naming what is known now, what new evidence arrived, and which estimate is being moved toward that evidence.

02 Agent–environment boundary

At each time step the agent receives a state, chooses an action, and the environment returns a reward and next state. Where you draw this boundary determines what the agent can control and observe.

03 The Markov property

A state is sufficient when it contains the information needed to predict the next outcome given an action. It need not record the entire history; it must summarize everything from history that still matters.

04 Return and discounting

The return Gₜ adds future rewards. Discount γ controls how strongly distant rewards count and makes continuing sums finite. In episodic tasks, termination naturally bounds the return.

05 State and action values

vπ(s) predicts return from a state under policy π. qπ(s,a) predicts return after taking action a and then following π. Values turn long sequences into locally useful predictions.

06 Bellman equations

A value equals expected immediate reward plus discounted value of the next state. This self-consistency equation is the engine behind dynamic programming and nearly every later update.

07 Worked example

walk it throughIn a recycling robot, states might be high or low battery. Searching can find cans but risks depletion; waiting is safer; recharging resets the battery. The transition probabilities and rewards define the MDP. An optimal policy can search aggressively when charged and recharge when low.

When you work through an example, keep the roles separate: the behavior policy produces experience, the target says what the current estimate should move toward, and the step size controls how far it moves. Many algorithms differ mainly in one of those three choices.

08 The easy mistake

watch outThe Markov property is not a claim that the real world has no memory. It is a property of the chosen state representation. If hidden history affects outcomes, the representation is partially observable.

09 Questions people actually ask

Do I need to memorize every equation?

No. First learn the update pattern: old estimate plus step size times an error. Then identify how the target is built and whether data comes from the same policy being evaluated. Derive or look up the exact form after the mental model is stable.

What should I implement first?

Use the smallest environment that exposes the chapter's idea. Print intermediate values, fix random seeds for debugging, and compare against a simple baseline before scaling to a neural network.

How do I know whether learning is real?

Evaluate on multiple seeds, separate training behavior from the target or greedy policy, report distributions rather than one run, and inspect learned values or policies—not only total reward.

10 Key takeaways

  • Agent–environment boundary: At each time step the agent receives a state, chooses an action, and the environment returns a reward and next state.
  • The Markov property: A state is sufficient when it contains the information needed to predict the next outcome given an action.
  • Return and discounting: The return Gₜ adds future rewards.
  • State and action values: vπ(s) predicts return from a state under policy π.
  • Bellman equations: A value equals expected immediate reward plus discounted value of the next state.
